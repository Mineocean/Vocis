# Vocis v0.4 设计：本地实时识别

日期：2026-08-02
状态：已批准（用户确认默认模型 base）

## 目标

v0.3 的延迟瓶颈已定位为**云端 ASR 网络往返**（MiMo 每 1.2s 一次 HTTP）。v0.4 将 ASR 改为**本地 faster-whisper**，实现离线、低延迟识别；DeepSeek 云端翻译保留；中文源音频直接显示原文不翻译。

## 约束（用户确认）

1. 延迟 + 离线都重要（非二选一）
2. 多语言自动检测（中/英/日）
3. **识别本地 + 翻译云端**（推荐方案已采纳）
4. **faster-whisper 打底 + NPU 探索留作后续**
5. 默认模型 **base**（实测 rt=0.99s/12.8s 音频，x12.86 实时，lang=zh prob=0.999）

## 硬件与环境

- CPU: Intel Core Ultra 7 255HX（20 核）
- GPU: RTX 5060 Laptop（Blackwell sm_120，torch cu126 不支持，暂走 CPU int8）
- NPU: Intel AI Boost（存在，openvino 未装，v0.5 探索）
- .venv: faster_whisper 1.2.1、huggingface_hub 1.18.0

## 架构

```
音频 → WASAPI Loopback → VAD 切段
        → faster-whisper 本地识别（多语言自动检测）
            ├─ 源语言 == 目标语言 → 直接显示原文（跳过翻译）
            └─ 否则 → DeepSeek 云端翻译 → 显示译文
```

增量实时管道（方案 D：滚动累积 + 文本差分 + 按句翻译）保持不变，仅替换 ASR 后端。

## 组件改动

### backend/asr/whisper.py
- `transcribe` / `transcribe_async` 返回类型从 `str | None` 改为 `(text, language, probability) | None`
- `_load_model` 用 `whisper_model_path` 配置直接加载本地模型目录（默认 `models/faster-whisper-base`），避免 HF 下载重定向坑
- 语言检测用 `WhisperModel.transcribe` 返回的 `info.language` / `info.language_probability`
- `set_language("auto")` → 每次识别自动检测语言（不再固定）

### backend/asr/base.py
- `ASREngine.transcribe_async` 签名同步改为返回三元组
- mock 后端：返回 `(text, "zh", 1.0)`
- mimo 后端：返回 `(text, None, 0.0)`（云端不暴露语言）

### backend/config.py
新增配置项：
- `whisper_model_path`（`WHISPER_MODEL_PATH`，默认 `models/faster-whisper-base`）
- `skip_translate_when_same_lang`（`SKIP_TRANSLATE_SAME_LANG`，默认 `true`）

### backend/pipeline.py
- 增量 worker 识别后拿到 `(text, lang, prob)`
- 语言映射：whisper ISO 码 `zh→中文`、`en→英文`、`ja→日文`
- **跳译判断**：`skip_translate_when_same_lang and mapped_lang == target_language` → 直接 emit 原文（译文为空）
- 低置信度（prob < 0.5）→ 视为语言不确定，保守走翻译路径

### gui/settings.py
- ASR tab：模型路径输入框（默认 `models/faster-whisper-base`）、"源语言=目标语言时跳过翻译"勾选

### 文档
- `.env.example`、README 更新新配置说明

## 数据流（增量模式）

```
每 1.2s: rolling音频 → whisper.transcribe_async → (text, zh, 0.999)
→ diff 新增 → 语言映射 zh==中文 → 直接 emit(原文, "", False)
→ 英文音频 → (text, en, 0.95) → en≠中文 → 切句翻译 → emit(原文, 译文, False)
段结束 → flush 残句 → emit(原文, 译文, True)
```

## 错误处理与降级

- whisper 模型缺失（`models/` 不存在）→ `create_asr` 警告 + 自动回退 MiMo 云端
- 识别失败（返回 None）→ 跳过本轮，下周期重试
- 语言低置信度（prob < 0.5）→ 走翻译路径

## 测试

- whisper 后端：mock 模型返回固定段，验证三元组解析
- pipeline 跳译逻辑：mock ASR 返回 zh + 目标中文 → 断言 emit 原文空译文；返回 en → 断言走翻译
- config：新配置项默认值
